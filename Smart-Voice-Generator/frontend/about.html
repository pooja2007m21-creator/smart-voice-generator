About

Smart Voice Generator is a Text and Speech Analysis project. It reads text aloud with the browser's built-in speech engine and reports basic statistics about the text.

Frontend

HTML5, CSS3, vanilla JavaScript and the Web Speech API.

Backend

Python Flask REST API for text analysis and history.

Database

SQLite stores each speech request with its voice, speed and pitch.

Limits

Voices depend on your browser and device. Audio download works only where the browser allows tab-audio capture.
